# Test corpus

`corpus.json` lists every file and the expected result:

- `"expect": "open"` with `pages`: opens and renders.
- `"expect": "password"` with `password`: shows the password prompt; the password opens it.
- `"expect": "error"` with `error` (`empty`, `not-pdf`, `damaged`): shows that clear message.

The Phase 1 gate test (`tests/e2e/open.spec.ts`) runs every entry in all five browser projects.

## Synthetic files

Generated by `npm run corpus` (`scripts/make-corpus.mjs`); regenerate rather than editing by hand.

## Real-world files (still to add)

The roadmap calls for about 40 files. Still missing: real government forms that are already
fillable, flat intake forms, scans and phone photos, non-Latin scripts, and XFA forms.
To add one, put it in this folder and add an entry to `corpus.json` by hand. Only use files
you are allowed to redistribute, and never use a filled-in form with real personal data.
Note that `npm run corpus` rewrites `corpus.json`, so hand-added entries must be added to the
script's output again (or moved into the script).
